BITWORKS

Build computers from tiny blocks. Wires carry ON/OFF, gates do logic, lights show the answer.

BUILD

Left drag place   Right drag erase
R rotate   Shift+drag straight line
Alt+drag wire that doesn't join others
F change color / speed / note
B LED brightness
Middle click / P pick block under mouse
1–0 quick pick
Click a switch or button to use it.

COPY

Ctrl+drag select   Ctrl C Ctrl X Del
Ctrl V paste (R rotates)
Ctrl Z undo   Ctrl Y redo

LINKS

L link tool: click the sender, then the receiver.
Any distance, any layer, only those 2 blocks.
Right-click a link to remove it.

MOVE

WASD move   Wheel zoom
Middle drag move   H home

RUN

Space pause   . one tick
[ ] speed   M mute

LAYERS (16)

Q layer down   E layer up   X see through all
Blocks touch the layer above and below.
V choose: above + below / below / above / none

HOW SIGNALS FLOW

Gates output where the arrow points.
They read from the back and sides.
NOT, diode and T flip-flop: back only.
Switches and clocks power all 4 sides.

Saves by itself. Click anywhere to start.
